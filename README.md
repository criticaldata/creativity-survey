# Neurosymbolic Creative AI

Code for the literature search underpinning the paper **"Creativity in
Human-AI Systems: A Neurosymbolic Architecture for Constraint Modulation"**.

The paper argues that creative capacity in human-AI systems comes from an engineered
tension between a divergent generation engine and a neurosymbolic convergent constraint
layer, drawing on psychedelic neuroscience (precision relaxation, REBUS) as a mechanistic
analogy, and grounds this in a PRISMA-ScR-guided scoping review across neurosymbolic AI,
cognitive architecture, uncertainty/exploration, ensemble methods, and psychedelic
neuroscience.
